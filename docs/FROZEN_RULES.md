# 冻结区改动规则

冻结区：`backend/manager`、`backend/pkg`（核心结构）。

## 允许直接改（不需要 Plan + 人工确认）

- 新增独立的函数/方法（不在任何接口中）
- 新增文件
- 新增独立的类型/常量
- 给已有 struct 添加新字段（不修改已有字段）
- 新增数据库迁移文件（不改已有迁移）

## 必须先 Plan + 人工确认

- 修改已有函数/方法的签名（参数、返回值）
- 修改已有 struct 字段的类型、名称、删除
- 给已有接口添加方法
- 修改已有 SQL 查询的语义
- 修改已有数据库表结构（除新增迁移）
- 移动/重命名已有文件
- 修改已有方法的行为（即使签名不变）

## 判断依据

改动后，已有代码的编译或行为是否发生变化？

- 否 → 直接做
- 是 → Plan + 人工确认

参考：`AGENTS.md` 硬规则第 11 条、`docs/ARCHITECTURE.md`。
